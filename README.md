# pingcell

Ping encode/decode helpers for cell payloads in pipelines.

**Site:** https://theworker02.github.io/pingcell/

## Install / run

```bash
git clone https://github.com/theworker02/pingcell.git
cd pingcell
node src/cli.js
node --test
```
